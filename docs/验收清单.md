# 第一版验收

## 软件界面

- 真实空间首次启动没有演示消息，显示 QQ 未连接。
- 点击“体验演示”出现演示提示；查看任务六要素及原文；完成一项后计数同步。
- 切换来源群、搜索、按优先级或自定义排序；点击周日程筛选任务。
- 待确认任务保存后进入正式待办；完成、恢复、编辑与删除均生效。
- 普通通知不会占用待办台；闲聊可标记不进入待办或配置关键词过滤。
- 查看本周/本月报告，缺少数据时用“—”，不虚构数据。
- 演示变化不会写入真实 QQ 数据库；退出演示后恢复真实空间。
- 悬浮窗置顶显示逾期、今日到期和高优先级任务，普通远期/已完成/待确认任务不混入重要任务列表。
- 拖动悬浮窗标题栏移动；收起/展开；关闭后可从“连接与设置 → 打开悬浮窗”恢复。
- 最小化主窗口，悬浮窗仍可见；点击悬浮窗任务恢复主窗口并打开正确任务详情；点击完成，两侧计数同步。
- 重启后恢复开关、位置和收起状态；切换演示模式时悬浮窗明确显示演示数据；关闭主窗口后悬浮窗退出。
- 点击右上角“使用说明”，切换快速开始、功能介绍、悬浮窗使用、数据与分享、常见问题；FAQ 可展开，操作按钮可跳转设置和待办。

## 真实接入（待用户环境验证）

1. 先在桥接端开启本机正向 WebSocket，配置访问 Token。拾序中连接，确认显示自己的 QQ 账号并列出真实群聊。
2. 选择一个测试群，在群内由你本人正常发送一条新通知，确认消息出现。不要使用软件向任何人发消息，它没有发送功能。
3. 在未选群中发送测试文本，不应保存或上传；断开后应停止接收。
4. 配置 AI，点击测试 AI 连接；开启云端解析后发送含两个独立任务的通知，应该生成两条待办，六要素与原文一致。
5. 时间缺失的通知进入待确认，未知字段明确标识；文件和图片仅显示占位；不要把附件里的任务期待为已提取。
6. 相同附件 ID 产生重复文件分类；同名不同 ID 不自动合并。不同桥接实现可能对同一文件分配不同 ID，这种情况第一版不能自动识别重复内容。
7. 设置闲聊关键词规则，后续同群包含关键词的消息自动过滤；删掉规则后恢复正常处理。
8. 关闭并重新启动拾序，任务和规则保留，密钥仍可用，真实连接需要手动重新连接。
9. 停止桥接服务，软件显示重连状态；重新开启后恢复接收。断线消息不回溯。
10. 打开 QQ 群与附件链接，在你的 QQ 版本上验证实际效果；无附件链接时回 QQ 查看。

- 全部验收后再决定安装包、签名、升级与许可证呈现方案。
