# 拾序 · 高校群消息待办助手

面向 Windows 10/11 x64 的个人 QQ 群消息管理应用。把选中群的新通知整理成待办，让截止时间和操作要求一眼可见。

## 下载安装

在本仓库 **Releases** 下载 `Shixu-Setup-0.2.0-x64.exe`，运行安装程序。无需安装 Node.js 或下载源码。安装包包含 Electron 和经过 SHA256 校验的 NapCat v4.18.30 原始桥接资源。桌面 QQ 客户端不包含在安装包中，请自行安装。

首次使用：
1. 打开“连接与设置”，点击“准备并启动桥接”。自动检测不到 QQ 时，选择已安装的 `QQ.exe`；也可通过页面入口下载桌面 QQ。
2. 复制登录口令，打开 QQ 登录页面，粘贴口令并用自己的手机 QQ 扫码。返回软件保存并连接，选择需要处理的群。
3. 填写自己的 AI 服务地址、模型和 API 密钥，启用云端解析并保存。可以先使用演示模式体验界面。

软件内“使用说明”包含功能介绍、悬浮窗用法、数据说明与常见问题。各用户的账号、任务和配置独立保存在自己的电脑上。

## 功能

- 仅处理连接后选中群的新消息；不读取历史和私聊。
- 文字、@所有人、图片、文件、语音占位信息；本版按需求不做 OCR、附件正文解析或语音转写。
- 提取责任人、办理条件、操作要求、截止时间、提交渠道和适用人群；多子任务独立拆分，缺失要素进入待确认。
- 待办、普通通知、闲聊、重复文件分类；按群关键词过滤、附件 ID 去重与合并。
- 待办完成、恢复、编辑、纠错、删除、来源群筛选、自定义排序和周日程。
- 置顶悬浮窗显示逾期、今日到期和高优先级任务，可拖动、收起、查看和完成。
- 周/月效率报告、群维度统计与不含密钥的 JSON 备份导出。
- API 密钥和桥接 Token 使用 Windows 本机加密；仅用户启用云端后，选中群的消息文本会直接发给所配置的服务商。

## 源码开发与构建

需要 Windows x64 和 Node.js 22.12+。

```powershell
npm ci
npm run bridge:fetch
npm start
```

`bridge:fetch` 从官方 Release 下载固定版本原始桥接并校验 SHA256；不会包含开发者个人 QQ 配置。构建安装包：

```powershell
npm test
npm run package
```

安装包输出到 `release/`。浏览器界面开发用 `npm run dev`，浏览器仅支持演示模式，真实接入需 Electron。桌面验收用 `node tests/desktop-smoke.cjs`，脚本创建独立测试数据，并使用模拟 QQ/AI 服务；不连接个人账号或收费 API。

## 数据与限制

应用数据位于 `%APPDATA%\shixu-qq-assistant\data.json`，桥接首次运行资源和登录状态位于同目录的 `bridge/`。消息与任务以明文 JSON 保存，密钥采用 Windows DPAPI 加密。不要把该目录、`.local-data/`、日志或备份上传到公开仓库。退出应用后不再接收消息或提醒，断线消息不会回溯。

QQ 接入采用第三方本地桥接，输入 QQ 号码或仅打开原版 QQ 不能读取消息。兼容性取决于 QQ 与桥接版本。群跳转依赖本机 QQ 协议，无法定位到指定原消息；无附件链接时需回 QQ 查看。发布版本未配置商业代码签名证书。
